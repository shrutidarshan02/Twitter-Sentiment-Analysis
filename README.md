# Sentiment Analysis EDA using Python

## Overview

This project performs Exploratory Data Analysis (EDA) on the Sentiment140
dataset containing 1.6 million tweets. The objective is to understand
sentiment distribution and identify patterns in tweet sentiment across
time and text characteristics.

## Dataset

- Dataset: Sentiment140
- Records: 1,600,000
- Sentiments: Positive and Negative
- Source: Sentiment140
- File: training.1600000.processed.noemoticon.csv

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- WordCloud
- Jupyter Notebook / Google Colab

## Project Workflow

1. Load the dataset
2. Rename columns
3. Explore dataset structure
4. Analyze sentiment distribution
5. Clean tweet text
6. Generate positive and negative word clouds
7. Analyze frequent words
8. Analyze sentiment by weekday
9. Analyze yearly and monthly trends
10. Analyze hourly sentiment patterns
11. Visualize findings

## Key Analysis

### Sentiment Distribution

The dataset contains an equal number of positive and negative records.

### Text Cleaning

URLs, mentions, hashtags and special characters were removed
before text-based analysis.

### Word Frequency

The most frequently occurring words were identified using word frequency
analysis.

### Time-based Analysis

Sentiment was analyzed across:
- Weekdays
- Years
- Months
- Hours of the day

## Key Findings

- The dataset has a balanced positive and negative sentiment distribution.
- Positive and negative tweets show different frequently used words.
- Sentiment patterns were explored across different time periods.
- Hourly and monthly analysis helped identify changes in sentiment activity.
